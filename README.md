# E-Commerce Customer Analytics

An end-to-end customer analytics project using **Python, SQL, and Power BI** to analyze e-commerce transaction data, understand customer purchasing behavior, and develop customer segments using RFM analysis.

## 📌 Project Overview

This project transforms raw e-commerce transaction data into structured customer-level analysis and business insights.

The workflow covers:

- Data cleaning and preprocessing using Python
- Exploratory and customer-level analysis
- RFM (Recency, Frequency, Monetary) analysis
- Customer segmentation
- SQL-based business analysis
- Interactive Power BI dashboard development
- Preparation of analysis outputs for reporting and decision-making

The project demonstrates how transaction-level data can be transformed into meaningful customer and business insights.

---

## 🎯 Project Objectives

- Understand customer purchasing behavior
- Clean and prepare raw transaction data
- Analyze customer revenue and purchasing activity
- Calculate RFM metrics
- Segment customers based on their purchasing behavior
- Perform business analysis using SQL
- Build an interactive Power BI dashboard
- Generate structured outputs that can support business decision-making
